# ChromaQuest
Chroma Quest is a vibrant, single-player web game build with HTML, Javascript, and Tailwind CSS. Dive into the magical realm of Chromaria, where you play as Lira, a shard-seer tasked with restoring the shattered Chroma Crystal. Match colorful shards in a 4x4 grid to harness their energy, guided by Elder Varyn's witty wisdom.
